Overview

RESTful API for accessing environmental sensor data. All endpoints return JSON.

GET /api/current

Get current sensor readings and comfort metrics.

{
  "timestamp": "2026-05-15T14:30:45.123456",
  "temperature": 25.3,
  "humidity": 55.2,
  "sensor_healthy": true,
  "stats": {
    "temp_min": 22.1,
    "temp_max": 26.5,
    "hum_min": 50,
    "hum_max": 65
  },
  "comfort_metrics": {
    "heat_index": 25.5,
    "dew_point": 15.3,
    "comfort_zone": "Comfortable",
    "comfort_icon": "☀️",
    "comfort_description": "Ideal conditions"
  }
}

GET /api/history

Get historical sensor data from CSV files.

Query Parameters:

  • date - Date in YYYY-MM-DD format (default: today)
  • limit - Maximum number of records (default: all)

Example:

GET /api/history?date=2026-05-15&limit=100

Response:

{
  "date": "2026-05-15",
  "count": 100,
  "readings": [
    {
      "timestamp": "2026-05-15 14:30:45",
      "temperature": 25.32,
      "humidity": 55.18,
      "heat_index": 25.50,
      "dew_point": 15.30,
      "comfort_zone": "Comfortable"
    }
  ]
}

GET /api/summary

Get summary statistics for a date range.

Query Parameters:

  • start - Start date YYYY-MM-DD (default: 7 days ago)
  • end - End date YYYY-MM-DD (default: today)

Example:

GET /api/summary?start=2026-05-10&end=2026-05-15

GET /api/health

System health check endpoint.

{
  "status": "healthy",
  "sensor_healthy": true,
  "last_update": "2026-05-15T14:30:45.123456",
  "data_available": true
}

Web Pages

The following web pages are available for viewing data:

GET /

Live dashboard with real-time sensor readings and comfort metrics.

GET /history

Historical data visualization with interactive charts.

GET /notes

Custom notes page for adding location info, maintenance logs, observations, and TODO items.

POST /notes/save

Save custom notes (used by the Notes page form).

Form Data:

  • notes - Text content to save

Response:

{
  "success": true,
  "message": "Notes saved successfully"
}

Usage Examples

cURL

# Get current readings
curl http://localhost:5000/api/current

# Get historical data
curl http://localhost:5000/api/history?date=2026-05-15

# Health check
curl http://localhost:5000/api/health

JavaScript (Fetch)

// Get current readings
fetch('/api/current')
  .then(response => response.json())
  .then(data => console.log(data));

// Get historical data
fetch('/api/history?date=2026-05-15')
  .then(response => response.json())
  .then(data => console.log(data));

Python

import requests

# Get current readings
response = requests.get('http://localhost:5000/api/current')
data = response.json()
print(data)

# Get historical data
response = requests.get('http://localhost:5000/api/history', 
                       params={'date': '2026-05-15'})
data = response.json()
print(data)
